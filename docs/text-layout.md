# 모든 영상에 적용하는 텍스트 비율 — layout v6

2026-10-11 사용자가 제공한 자동차 창문 이미지의 비율을 확정했다. 모든 새 영상과 재렌더에 반드시 적용한다. 다른 주제·언어에서도 위치와 크기 비율은 유지한다. 기존 완료 영상의 미디어는 자동으로 변경하지 않는다.

설정의 단일 기준은 `config/higgsfield-typecast.json`의 `layout`, `captions`, `captions_en`. 주제 파일은 글자 내용·줄바꿈·강조어만 제공하며 레이아웃을 덮어쓰지 않는다. 과거 v1~v5 문서·완료 검수 기록에 남아 있는 좌표는 현재 지시가 아니다.

| 항목 | 1080×1920 기준 | 화면 비율 |
|---|---|---|
| 제목 블록 중심 | x=540, y=260 | 가로 50%, 높이 약 13.5% |
| 제목 허용 영역 | y=100~440 | 높이 약 5.2~22.9% |
| 제목 | 기본 108px, 긴 경우 최소 84px, 최대 두 줄 | 최대 폭 87% |
| 자막 블록 중심 | x=540, y=1360 | 가로 50%, 높이 약 70.8% |
| 자막 허용 영역 | y=1230~1470 | 높이 약 64.1~76.6% |
| 자막 | 64px, 최대 두 줄·최대 7어절·28자 | 최대 폭 74% |

제목은 영상 내내 같은 하나의 블록이다. 보통 첫 줄 흰색, 둘째 줄 노란색(#FFD400). 굵은 한글 산세리프, 가벼운 기울임, 어두운 14px 외곽선과 부드러운 그림자. 자막은 흰색에 주제 강조어만 노란색, 어두운 8px 외곽선과 그림자. 제목/자막 뒤의 배경 패널·띠·박스·블러 없음. 진행 칩·단계 제목·부품 라벨 없음.

한 줄과 두 줄은 **블록 전체 중심을 동일하게** 유지한다. 기울어진 제목의 글자 끝과 외곽선까지 포함한 실제 픽셀 경계를 가로 중앙에 맞춘다. 줄이 길면 먼저 의미 단위로 줄바꿈하고 최대 두 줄 안에서 정해진 글꼴 범위로 맞춘다. 주제마다 제목을 다시 작게 만들거나 위치를 올리지 않는다. 다른 9:16 해상도는 좌표·글꼴·외곽선·그림자·줄 간격을 모두 같은 배율로 변환한다.

그림은 전체 화면에 채운다. 주요 물체가 중간에서 전체 모습을 보여 주도록 구도를 잡고, 자막으로 수면이나 비교 결과가 가려지지 않게 한다. 위 90px·아래 440px·오른쪽 UI 열(x≥960, y≥900)은 텍스트를 비운다. 이 여백은 제작 기준이며 모든 기기의 공식 safe area라는 뜻은 아니다. 사용자 최신 첨부 비율에 따라 예전 상단 500px 금지 규칙은 폐기했다.

최종 합성 전 확인:

제작 시작 스크립트는 `scripts/validate-layout.ps1`로 공통 설정과 모든 주제의 상속을 검사한다. 비율이 바뀌거나 주제별 덮어쓰기가 생기면 시작을 중단한다. 픽셀 위치의 최종 검수는 별도로 실제 영상에서 수행한다.

1. 공통 layout.version=6와 각 topic의 inherit_global=true, override_allowed=false.
2. 제목/자막 실제 픽셀(외곽선·그림자 포함)이 각 영역과 최대 폭 안에 있다.
3. 각 줄 좌우 여백 차 2px 이내. 한 줄/두 줄 모두 같은 블록 중심.
4. 시작·중간·끝·최장 자막을 360px 폭으로 보고 UI 마스크·9:19.5·9:20 표시에서 확인한다.
5. 글자 패널·진행 라벨 없음. 주요 물체/측정 결과를 가리지 않는다. 컷마다 위치가 바뀌지 않는다.

왕관 예시 제목: `무게는 똑같은데` / `진짜 금일까?`. 자막: `저울은 수평입니다`. 실제 완성 영상의 제목 내용은 주제의 title_fixed/title_fixed_lines로 정한다.

2026-10-11 v6 수정: 설명 자막만 54px 아래로 이동했다. 제목은 v5와 동일하다. 문장별 의미 단위의 줄바꿈을 미리 작성하고, 단어 시각에 맞춰 모든 원문을 빠짐없이 표시한다. 완료된 v1/2d-v3 미디어와 검수 기록은 당시 v5로 보존한다.
