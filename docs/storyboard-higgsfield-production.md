# 콘티를 유지하는 Higgsfield 제작

왕관 주제의 현재 입력은 `topics/archimedes-crown/storyboard-v3.md`, `higgsfield-v4.json`, `narration.txt`, `captions-ko.json`이다. 10장면 콘티의 스타일과 상태 변화는 유지하되, 콘티 보드 자체를 움직이는 영상으로 만들지 않는다.

1. 콘티의 같은 금덩이·낮은 올리브 잎 왕관을 사용해 세로 단일 장면의 깨끗한 시작·끝 이미지를 만든다. 제목·화살표·점선 이전 위치·여러 시점의 중복 물체는 영상 입력에서 제거한다. 각 이미지의 컵 크기, 물체 좌우와 재질을 확인한다.
2. 핵심 침수 장면부터 시작/끝 이미지로 Kling 3 Pro 무음 5초를 생성한다. 접촉 전에 물이 상승하거나 왕관 형태가 바뀌면 전체를 생성하기 전에 그 장면을 고친다. 실제 생성 중간 프레임까지 확인한다.
3. 같은 끝 이미지를 다음 시작 이미지로 공유하며 착지·저울 비교·물통 이동·침수·수위 비교/빈 고리 관찰·인양/린넨 복귀를 연결한다. 10개의 이야기 단계가 반드시 10개 생성 클립일 필요는 없다. 긴 장면에서는 실제 비교 상태를 유지하며 작은 시점 변화와 반사를 사용한다.
4. 검증된 필재 원음과 단어 시각을 재사용한다. 음성을 빠르게 하거나 자르지 않고, 그림의 동작 시각을 음성에 맞춘다. ‘수평’ 설명 시점에는 저울이 실제 수평이어야 한다. 잘못된 클립은 그 부분만 재생성한다.
5. 한글 줄바꿈은 합성 전에 `captions-ko.json`에 의미 단위로 작성한다. 원문 누락 여부와 각 줄의 픽셀 폭을 측정한다. 공통 layout v6의 제목 중심 y=260과 자막 중심 y=1360을 읽으며, 주제별 좌표 덮어쓰기는 금지한다. 컵/왕관을 자막이 가리면 그림 구도를 조정한다.
6. 실제 착지·저울·물 접촉·인양에 작은 효과음을 맞춘다. 생성 모델의 음성은 끄며 필재 설명이 주가 된다. 최종 파일 전체를 디코드하고 시작/중간/끝, 최장 자막, 수평/초기 수위/침수/인양 상태와 폰 화면 비율을 확인한다.

현재 로컬 명령:

```powershell
./scripts/validate-layout.ps1
python work/archimedes-crown/higgsfield-v4/overlays.py
python work/archimedes-crown/higgsfield-v4/assemble.py
python work/archimedes-crown/higgsfield-v4/verify.py
```

위 제작 소스와 매체는 사용자 요청에 따라 로컬에만 있다. Git은 재생성에 필요한 환경 설정·입력 문장·프롬프트·명령·검수 기준을 공유한다. API 키, 업로드 서명 주소와 생성 파일을 커밋하지 않는다. 이미 제출한 작업은 로컬 job 기록을 확인한 뒤 이어서 처리하며, 기다리기 시간이 끝났다는 이유로 다시 제출하지 않는다.

일러스트의 수위 차이는 이해를 위한 확대다. 금 순도나 금속 부피의 수치를 계산한 결과가 아니다. 원본 콘티와 생성 영상이 픽셀 단위로 완전히 같지는 않으며, 물리 상태와 물체 정체성을 실제 출력으로 검수한다.
