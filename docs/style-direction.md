# 승인된 이미지 느낌과 새 이야기 기준

2026-10-11 사용자: 생성한 버클 이미지 느낌은 좋지만 ‘버튼이 있고 이렇게 작동합니다’로 끝나는 접근은 원하는 방향이 아님. 이후 안전핀은 너무 단순하다고 제외. 추가로 ‘지금은 당연하지만 옛날에는 어떻게 했을까’라는 역사적 난관·발견 이야기도 원함. 왕관의 금 순도 판별을 예로 제시.

## 유지할 이미지 느낌

- 단순한 형상에 실제 재료처럼 보이는 은은한 표면 결, 작은 베벨, 부드러운 접촉 그림자.
- 밝은 회색 배경, 또렷한 주인공, 전체 물체가 보이는 중간 거리 구도.
- 움직임의 전후가 구별되는 조립·접촉·분리 장면. 강한 줌 대신 부품의 동작으로 관심을 유지.
- 금속은 부드러운 반사, 천은 직조 질감. 재료를 모두 매끈한 플라스틱처럼 만들지 않음.

로컬 참고 이미지: `work/style-references/buckle-style-v2.png`. 안전핀 비교 보드는 `work/style-references/safety-pin-concept-v2.png`이며 채택된 주제가 아니다. 둘 모두 이미지 생성 도구로 만든 기획 보드다. 실제 Blender 렌더나 검증된 동작 프레임이 아니다. 생성 이미지의 손가락 접촉·부품 변형·글자 좌표를 영상의 정답으로 사용하지 않는다.

## 바꿀 이야기

기존 방법 → 화면에 드러나는 문제 → 필요한 구조 수정 → 개선으로 남는 한계 → 추가 수정 → 지금 사용하는 모습.

대본을 먼저 작동 부품 목록으로 쓰지 않는다. 각 개선 장면 전에 ‘무엇이 불편했고, 왜 이 모양이 필요했나’가 있어야 한다. 실제 개선 이력과 구조 설명용 가상 비교를 구분한다.

역사적 문제 해결형은 **과거의 제약 → 실패하거나 불충분한 시도 → 관찰·발견 → 해결 → 현재도 이해되는 원리**로 전개한다. 모든 주제에 부품 개선을 두 번 강제하지 않는다. 인물의 과장된 반응은 현대 화자의 연출로 쓰고, 사건·전승·가상 비교를 구분한다. 세부 역사보다 ‘왜 그 방법이 통했는가’를 움직임으로 설명한다.

## 영상에서 따로 확정할 것

이미지 보드는 색·질감·가독성 방향의 예시다. 최종 9:16 영상에서는 config layout v4대로 제목 y=580, 자막 y=1260, 가로 중앙, 외곽선·그림자만 사용한다. 이미지 보드의 제목/자막 위치는 v4 검수 통과 상태가 아니다. 폰 표시 비율과 UI 마스크로 최종 확인한다.

Blender가 정확한 기구 동작을 담당하고, Higgsfield 보조 컷도 승인된 구조와 상태를 이어받는다. 한국어 Typecast 필재만 적용한다. 영상·음성·모델·생성 이미지 파일은 Git에 넣지 않는다.
