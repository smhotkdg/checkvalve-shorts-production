# 장부맞춤 레퍼런스 상세 분석

분석일: 2026-10-11. 대상: [못 없이 나무를 이어 붙이는 전통 목공 기술, 장부맞춤](https://www.youtube.com/watch?v=Gko5JrBC020), 이런거지 채널.

## 확인 방법과 정확도

- 실제 YouTube 플레이어의 전체 길이 **27.221초**를 확인했다. 브라우저의 대표 프레임(0, 2.72, 5, 8.16, 10, 13.60, 15, 16.32, 19.04, 20, 21.76, 24.48, 25초)과 한국어 자동 자막 타임스탬프를 대조했다.
- 아래 구간은 발화와 화면 변화에 맞춘 **대략적인 분석 범위**다. 컷 경계의 프레임 단위 실측표가 아니다. 자동 자막에는 오인식이 있어 원문 대본으로 사용하지 않는다.
- 최초 영상 분석 도구의 8개 장면 요약은 순서 파악에만 사용했다. 직접 확인하면 10초에도 줄 연결이 남아 있고, 20초는 맞물림 중심, 21.76초는 사각 구멍 가공, 24.48초는 건축물이다. 따라서 기존 요약의 18~23초 전체를 쐐기 삽입으로 보는 시각 배분은 폐기한다.
- 실제 제작 프로그램, 렌더 엔진, 원래 TTS 서비스·성우, 오디오 속도·음량 수치는 공개 화면만으로 확인하지 못했다. 부드럽게 보이는 이유와 제작 제안은 관찰에 근거한 해석이다.
- 원본 영상·전체 자막·스크린샷은 Git에 복제하지 않는다. 문장과 장면은 새 주제로 새로 작성한다.

## 왜 계속 이어지는 느낌이 드는가

**컷 없는 한 테이크가 아니라, 원인과 결과가 끊기지 않는 편집이다.** 비교 → 실패 → 가공 → 맞물림 → 재실패 → 추가 잠금 → 사용처가 이어진다. 화면을 바꿔도 앞에서 생긴 문제와 그 연결부를 이어받는다. 서로 무관한 예쁜 장면의 나열이 아니다.

시청자의 예측을 두 번 바꾼다. 처음에는 줄로 연결하면 될 것 같지만 높이가 맞지 않는다. 그다음에는 촉과 홈이면 될 것 같지만 뽑힐 수 있다. 쐐기는 두 번째 실패에 직접 대응한다. 모든 난관이 실제 눈에 보이는 위치·형태 변화와 짝을 이룬다.

대사는 물체의 동작을 앞뒤로 묶는다. 한 번에 모든 원리를 설명하지 않고, 현재 실패가 왜 다음 조작을 필요로 하는지 말한다. 질문을 마지막까지 무조건 숨기기보다 해결을 조금씩 보여 주고 마지막에 명칭과 적용을 정리한다. 이 영상에서 어울리는 핵심 동사는 연결, 깎기, 끼우기, 빠짐, 뚫기, 잠금이다.

## 질감과 카메라

- 목재는 둥근 외곽, 길이 방향의 나무결, 절단면, 넓고 부드러운 밝은 반사띠가 함께 있다. 완전 무광 단색 도형보다 재료를 구별하기 쉽다. 그러나 사진 같은 고해상도 재질이나 특정 PBR 설정을 사용했다고 단정할 수 없다.
- 바닥 타일의 원근과 부드러운 그림자가 깊이와 위치를 잡아 준다. 나무·돌·하늘 배경은 같은 공간이라는 느낌을 유지한다. 새 영상에 나무나 바위를 그대로 넣을 이유는 없다.
- 단부와 연결부를 보는 사선 화면, 좌우 정렬을 보는 비교적 정면 화면을 교대한다. 끝부분 가까이 보이는 장면도 있어 항상 전체 막대가 다 보이는 영상은 아니다. 우리는 사용자 피드백에 맞춰 전체 연결 관계가 남는 중간 거리를 우선한다.
- 최종 건축물에서 규모가 커진다. 모든 구간에서 카메라를 크게 움직일 필요는 없다. 물체의 상태 변화가 줄거리를 담당하고, 시점 변화는 필요한 면을 드러내는 역할이다.
- 원본의 정확한 줌 배율, 카메라 렌즈, 정지 구간 최대 길이, easing 수치는 실측하지 않았다. 1.15배 확대 상한·0.4초 easing은 우리 프로젝트의 제작 기준이다.

## 글자와 음성 구성

- 원본은 9:16 안에 검정 상단·하단 여백과 중앙의 거의 정사각형 애니메이션 창을 둔다. 중앙 영상이 전체 세로 화면을 채우는 형식은 아니다.
- 상단 고정 제목은 흰색·노란색 두 줄, 굵고 기울어진 글씨. 발화 자막은 애니메이션 창 아래쪽에 흰 글자와 두꺼운 어두운 외곽선으로 표시되며 독립된 자막 패널은 없다.
- 플레이어의 별도 자동 자막은 원본에 구워진 자막과 구분했다. 큰 검정 자동 자막 상자는 레퍼런스 디자인의 일부로 모방하지 않는다.
- 자동 자막의 발화 묶음은 대체로 1~3초 간격이다. 이는 자막 묶음의 시각이며 말하기 속도나 문장 길이의 정확한 측정값이 아니다. 이번에는 **Typecast 필재 한국어**를 실제로 생성·측정한 뒤 화면을 맞춘다.
- 음성의 원래 서비스나 필재와 동일한 목소리인지 확인되지 않았다. 원본 자동 자막에 음악 표식이 있으나 그 정보만으로 효과음 종류·믹스 수준을 판정하지 않는다. 새 영상의 회전음·금속 접촉음은 별도 연출 제안이다.

## 우리 영상에 반영하는 규칙

1. 같은 주인공 부품과 같은 단면을 유지한다. 조립 상태를 장면마다 초기화하지 않는다.
2. 2~3초마다 설명에 필요한 상태 변화를 설계한다. 카메라 흔들기·배경 입자·떠다니는 글자로 움직임을 대신하지 않는다.
3. 핵심 접촉 전후를 모두 보여 준다. 결과 프레임으로 점프하지 않고 접근→접촉→반응→안정 순서.
4. 실패와 개선이 각각 눈에 보여야 한다. 가상의 역사나 가짜 시공 문제를 만들어 사실처럼 설명하지 않는다.
5. 고정된 물체는 고정한다. 하중 시험에서는 당기는 쪽·하중 반응이 움직이고 고정된 앵커가 흔들리거나 빠지면 안 된다.
6. 은은한 재질·작은 베벨·부드러운 그림자를 추가하되 부품 개수는 늘리지 않는다. 전체/중간 거리 85% 이상, 기본 단면 70% 이상, 최대 3개 시점.
7. 레퍼런스의 검정 여백과 높은 제목 위치는 그대로 옮기지 않는다. 사용자가 이후 확정한 **layout v5**(풀 화면, 큰 두 줄 제목 블록 중심 y=260, 자막 블록 중심 y=1306, 배경 패널 없음)를 유지한다.
8. 마지막 실사용 장면은 앞의 원리와 연결한다. 잠금 해제 없이 억지로 최초의 빠지는 상태로 돌아가는 루프를 만들지 않는다.

## 선정 주제

**콘크리트 속에서 벌어지는 앵커볼트**. 빠지는 막대 → 끝 원뿔과 분할 링 → 꽂기만 하면 헐거움 → 너트를 조여 원뿔 이동 → 링 확장과 벽 접촉 → 고정 → 받침 사용. 부품이 적고, 움직임 방향이 명확하며 두 번의 상태 대비를 구성하기 쉽다. 큰 시설·물 시뮬레이션이 없어 이전 타워크레인보다 제작 범위를 작게 유지할 수 있다.

다른 후보: 라쳇 렌치(역방향 헛돎→폴 잠금), 지퍼(분리→슬라이더→치아 맞물림). 앵커는 숨은 부분을 단면으로 보여 주는 보상이 가장 분명해 이번 우선 주제로 선정했다.
