## 실제 제작 순서와 필요한 모듈

1. 주제 선정: 체크밸브가 역류를 막는 원리 하나로 범위를 좁혔습니다.
2. 사실 확인: 스프링식 마개 구조를 선택하고 제조사 자료로 개방·닫힘·최소 개방 압력 차를 확인했습니다.
3. 대본 작성: 약 45초 분량으로 압축하고 6개 장면을 설계했습니다.
4. TTS: edge-tts로 Microsoft 한국어 InJoon 음성을 생성했습니다. 50초를 넘는 초안은 문장을 줄여 다시 생성했으며, 완성 음성은 속도를 인위적으로 늘리거나 줄이지 않았습니다.
5. 2D 애니메이션: Python의 Pillow·NumPy로 시트·마개·스프링·유체 입자를 직접 그렸습니다. 같은 구조가 모든 장면에서 유지되고, 스프링 압축량과 마개의 이동이 함께 변합니다.
6. 영상·음성 결합: FFmpeg로 1080×1920 MP4를 만들고 음량을 정규화했습니다.
7. 자막: faster-whisper로 실제 음성을 분석해 시간 정보를 얻었습니다. 자막 문구는 최종 대본을 사용하고 Noto Sans CJK KR 글꼴로 화면에 삽입했습니다.
8. 최종 확인: 길이, 영상·음성 스트림, 전체 디코딩, 대본 누락, 자막 화면을 확인했습니다.
9. 납품: 자막과 음성이 포함된 MP4 하나, 제목·설명·최종 대본을 제공합니다.

## 원리와 표현 범위

- 정방향은 왼쪽에서 오른쪽입니다.
- 압력 차가 스프링의 저항을 이길 만큼 충분하면 마개가 이동하고 스프링이 압축됩니다.
- 물은 열린 틈으로 마개 주변을 지나갑니다.
- 압력 차가 줄어들면 스프링이 마개를 시트 쪽으로 되밀고, 역압도 닫힘을 돕습니다.
- 최소 개방 압력 차는 열리기 시작하는 조건이며 완전히 열린 상태의 조건과 다릅니다.
- 스프링식 구조를 설명하는 개념도입니다. 모든 체크밸브가 이 구조인 것은 아닙니다.
- 압력 막대와 유체 입자는 정성적인 설명용 표현입니다. 실제 수치·압력 손실·누설량을 계산한 시뮬레이션은 아닙니다.
