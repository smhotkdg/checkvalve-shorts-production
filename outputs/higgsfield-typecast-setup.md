# Higgsfield + Typecast 필재 제작 준비

기준일: 2026-10-10. **설정·샘플 요청 준비 완료, 계정 조건 미충족으로 새 영상 생성은 대기 중입니다.**

## 제작 목표

참고 채널의 문제 제시 → 내부 구조 → 부품 움직임 → 작동 조건 구성, 큰 제목과 짧은 한국어 자막을 유지합니다. 기존 체크밸브 대본으로 50초·9:16 샘플을 만듭니다. 새 영상의 음성은 Typecast **필재**로 고정하며 다른 음성으로 대체하지 않습니다. 기존 InJoon 납품본은 보존합니다.

## 준비한 실행 경로

1. 로컬 준비 도구가 대본과 이미지·영상 요청 초안을 생성합니다.
2. Typecast 계정을 인증해 실제 필재 제공 여부를 확인합니다.
3. 필재로 대본을 읽은 WAV를 생성하고 길이와 실제 발화를 측정합니다.
4. Higgsfield 연결 도구에서 동일한 스타일·구조의 이미지 자산을 만들고 검사합니다.
5. 승인된 자산의 실제 ID를 요청에 넣어 10초 영상 5개를 생성합니다. 먼저 1개를 검사한 뒤 나머지를 진행합니다.
6. 완료된 클립만 순서대로 편집하고 생성 영상의 원래 음성은 사용하지 않습니다. 최종 필재 음성에 맞춰 장면 전환과 한국어 자막을 맞춥니다.
7. 50초 최종 MP4, 제목·설명·대본을 검수하고 전달합니다.

Higgsfield는 이 대화에 연결된 도구를 통해 실행합니다. 준비 스크립트 자체가 Higgsfield 서버에 작업을 제출하는 프로그램은 아닙니다. 다른 환경에서 이어갈 때도 Higgsfield 연결이 필요하며, 공개 API를 별도로 쓴다면 인증과 과금 방식이 달라집니다.

## 직접 설정할 사항

| 항목 | 현재 확인 | 필요한 설정 |
|---|---|---|
| Higgsfield 연결 | 연결됨 | 같은 연결 계정으로 이어가기 |
| 생성 조건 | 무료 플랜, 0크레딧; 이전 첫 요청은 Basic 이상 요구로 거부 | 선택 모델을 사용할 권한과 생성에 필요한 크레딧 확인 |
| 무료 생성 | Genjutsu용 1회, 최대 30초·480p/720p | 이번 50초 MiniMax 경로에 적용할 수 없음 |
| Typecast API 키 | 환경 변수·암호화 파일 모두 없음 | API 콘솔에서 키를 준비해 로컬 입력 도구 실행 |
| 필재 API 지원 | 인증 전이라 미확인 | 실제 음성 목록에서 조회 성공 필요 |
| Typecast 사용 조건 | 계정별 미확인 | API 크레딧·상업 이용 조건 확인. Studio 구독과 별도 |

키를 채팅이나 Git에 올리지 마세요. Windows에서 `outputs/connect-typecast.ps1`을 실행하면 숨김 입력으로 저장하고 읽기 전용 목소리 조회를 수행합니다. 실제 생성은 별도 명령입니다.

## 준비 명령

```sh
python src/prepare_production.py
```

`work/higgsfield-typecast/narration-script.txt`, `requests-draft.json`, `preparation-report.json`을 만듭니다. 기본 실행은 API를 호출하거나 크레딧을 쓰지 않습니다. 미완성 참조 ID를 생성 도구에 보내면 안 됩니다.

Typecast 키가 환경 변수에 설정된 터미널에서 다음 명령으로 실제 음성을 생성할 수 있습니다. 계정 크레딧을 사용하며 아직 실행하지 않았습니다.

```sh
python src/typecast_api_bridge.py --generate --script work/higgsfield-typecast/narration-script.txt --out outputs/piljae.wav
```

## 비용과 제작 방식 비교

현재 연결 도구의 견적: Seedream 1K 이미지 1장 **1.25크레딧**, MiniMax 2K·10초 영상 1개 **20크레딧**. 실제 작업을 제출하지 않은 견적입니다.

| 구성 | 계산 | 예상 Higgsfield 생성 크레딧 |
|---|---|---:|
| 50초 전체 생성, 이미지 3장 | 5×20 + 3×1.25 | 103.75 |
| 위 구성 + 영상 1개 다시 생성 | 103.75 + 20 | 123.75 |
| 위 구성 + 영상 2개 다시 생성 | 103.75 + 40 | 143.75 |
| 영상 5개 전부 다시 생성 | 103.75 + 100 | 203.75 |
| 보조 영상 10초만 생성, 이미지 3장 | 20 + 3.75 | 23.75 |
| 보조 영상 20초만 생성, 이미지 3장 | 40 + 3.75 | 43.75 |

재생성률을 실측한 통계가 아닙니다. 재생성 횟수별 예산 시나리오입니다. Typecast, 추가 이미지, 별도 유료 편집·업스케일 비용은 포함하지 않습니다. 공개 API 달러 요금과 이 연결의 크레딧을 서로 환산하지 않습니다.

기계 내부 원리를 설명할 때는 부품 이동·스프링 압축·유체 경로를 직접 설계하는 편이 검사와 수정에 유리합니다. 그래서 핵심 원리 장면은 직접 제어하는 2D 또는 Blender, 도입·배경 컷은 Higgsfield, 음성은 필재인 구성을 권장합니다. 이 권고는 제작 판단이며 참고 채널이 실제로 이런 도구를 쓴다는 의미가 아닙니다. 사용자가 요청한 전체 Higgsfield 경로는 설정에 유지했고, 권장 대안으로 자동 변경하지 않았습니다.
