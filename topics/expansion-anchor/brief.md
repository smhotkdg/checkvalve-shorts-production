# 콘크리트 속에서 벌어지는 앵커볼트

상태: 주제·한국어 대본·연출 초안. 사용자 요청에 따라 선정. 음성/유료 생성/모델링/완성 영상은 아직 실행하지 않았다.
언어: **한국어만**. Typecast 필재 + 한국어 자막. 영어 파일은 새로 만들지 않는다.
레퍼런스: [장부맞춤](https://www.youtube.com/shorts/Gko5JrBC020), [상세 분석](../../docs/references/Gko5JrBC020-analysis.md).

## 선택 이유와 목표

이번 영상의 핵심은 금속 링의 상태 변화다. 줄거리의 각 장면이 같은 단면의 이전 상태를 이어받는다. 거대한 배경 없이 막대가 빠지는 실패, 원뿔과 링의 추가, 조임과 확장, 고정 결과를 계속 보여 줄 수 있다. 목표 약 **40초**이며 필재 실측 전의 임시 길이다. 실측 음성이 길면 영상도 늘린다. 특정 제조·발명의 역사처럼 묘사하지 않고 구조를 설명하기 위한 가상 비교로 시작한다.

핵심 사실: 너트를 조이면 나사봉 끝의 원뿔이 팽창 링 안으로 당겨진다. 링이 구멍 벽을 누르고, 압력으로 생긴 마찰을 통해 고정한다. 너트·와셔는 외부 받침을 콘크리트 표면에 밀착시킨다. 원뿔은 볼트와 한 몸이고, 링은 그 위에서 벌어진다.

## 대본에 대응하는 장면표 (필재 생성 후 재배분)

| 임시 시각 | 대본 줄 | 앞 상태 → 동작 → 결과 | 화면 / 소리 |
|---|---|---|---|
| 0~4 | 1 | 이미 삽입된 매끈한 비교 막대를 당김 → 구멍에서 쑥 빠짐 → 짧게 감속 | 기본 사선 단면, 전체 구멍과 막대 끝이 보임 / 가벼운 미끄러짐 |
| 4~7 | 2 | 같은 막대가 구멍 밖에서 멈추는 동안 링 위치가 드러남 → 다음 구조 준비 | 같은 공간 유지, 설명 카드 없음 |
| 7~12 | 3 | 구멍 밖에서 막대 끝 원뿔이 드러남 → 분할 링이 미끄러져 둘러짐 → 삽입 준비 | 가상의 구조 비교이며 현장에서 막대를 깎는 묘사 금지 / 금속 접촉 |
| 12~16 | 4 | 같은 앵커를 구멍에 삽입 → 아직 벽과 링 사이 간극이 남음 → 작은 당김으로 헐거움 제시 | 고정 단면, 링을 꽃처럼 과장하지 않음 |
| 16~21 | 5 | 바깥 너트 회전 → 받침·와셔가 벽에 먼저 밀착 → 그 반력으로 나사봉과 원뿔이 바깥으로 조금 당겨짐 | 너트와 내부 원뿔을 한 화면에서 볼 수 있음 / 회전음 |
| 21~26 | 6 | 같은 원뿔이 링 안으로 이동 → 링 조각이 방사 방향으로 벌어짐 → 벽 접촉 | 핵심 접촉을 0.5~0.8초 완만하게 강조, 화면 확대 없이 / 묵직한 접촉음 한 번 |
| 26~30 | 7 | 링이 벽을 누른 상태 → 시험 당김 → 앵커 위치 유지 | 당기는 대상만 움직임, 벽과 앵커는 고정 / 당김음 |
| 30~33 | 8 | 축 방향과 방사 방향의 힘 화살표를 차례로 보여 줌 → 화살표 제거 | 최대 두 개, 글자 없음, 이전 잠금 상태 유지 |
| 33~35 | 9 | 이미 밀착한 너트·와셔·받침의 외부 모습을 보여 줌 → 회전 도구가 물러남 | 잠금 상태를 풀지 않으며 새 간극을 만들지 않음 / 짧은 도구 이탈음 |
| 35~40 | 10 | 단면에서 같은 받침 실사용으로 연결 → 하중이 내려앉음 → 원리와 용도 정리 | 작은 선반을 포함한 중간/와이드. 마지막 5초 Higgsfield 보조 계획 |

줄 3~4의 비교 막대와 완성 앵커는 재질·축·공간을 이어받지만 동일 제품이라고 속이지 않는다. 완성 앵커를 삽입한 뒤에는 원뿔/링/너트의 구성과 조립 상태를 끝까지 보존한다. 하중 장면은 개념적 연출이며 제품별 파괴 하중이나 토크값을 암시하지 않는다.

## 3D, 질감, 움직임

- 큰 부품 6개 그룹: 콘크리트 단면과 구멍, 비교 막대/원뿔 일체 나사봉, 분할 링, 너트·와셔, 받침·선반, 회전 도구 프록시. 나사산은 회전 원리 이해에 필요한 디테일 예외. 여분 볼트·철근·브랜드·치수 없음.
- 링을 주황색 주인공으로, 나사봉·너트는 은은한 브러시 금속, 벽은 밝은 회색 콘크리트 결. 작은 베벨, 부드러운 그림자. 페인트 같은 단색이나 거울 같은 강한 반사만으로 처리하지 않는다.
- 너트는 화면 왼쪽 바깥, 벽 속은 오른쪽. 삽입은 오른쪽, 조임 때 원뿔 이동은 왼쪽, 링 확장은 위·아래 방향. 측면을 뒤집지 않는다. 링은 벽에 닿은 뒤 원뿔과 함께 통째로 빠져나오지 않는다.
- 기본 사선 단면 70% 이상, 전체/중간 거리 85% 이상, 시점 최대 3개. 같은 컷에서 확대 1.15배 이하, detail 최대 3초, easing 최소 0.4초. 나사봉 일부만 가득 채우는 강한 줌 금지.
- 2~3초마다 의미 있는 상태 변화. 고정된 앵커를 계속 움직이게 만드는 오류 금지. 긴 설명은 줄이고 시험 당김·도구 회전·조립·하중 등 화면 사건으로 이어 준다.
- 스타일 프레임: (1) 빠지는 막대 전체 단면 (2) 원뿔+링 구조 (3) 링이 벽에 닿는 순간 (4) 받침 적용. 네 장과 360px 축소 검수 전 전체 렌더/유료 생성 없음.

## Blender + Higgsfield + Typecast

1. Typecast 필재 목록 조회, 현재 비용 확인, 승인된 생성 후 음성 실측. 0.94 처리 음성+끝 여유에 맞춰 최종 길이·장면표 확정. 한국어만.
2. 모든 기구 동작은 Blender에서 제어. 카메라보다 부품 움직임이 줄거리를 만든다.
3. Higgsfield는 마지막 약 5초의 같은 받침 적용 장면을 승인된 Blender 시작/끝 프레임으로 보조하는 계획. 도구가 물러나고 가벼운 시차가 생기되 고정된 앵커는 움직이지 않는다. 제품·새 부품·글자 생성 금지. 현재 견적 미조회, 크레딧 사용 없음.
4. 효과음보다 필재가 크게. Whisper로 실제 최종 한국어 음성을 분석하고 원본 대본 문구를 사용한다.
5. 자막과 고정 제목은 공통 layout v5. 제목 블록 y=260(최대 두 줄·108px·폭 87%), 자막 블록 y=1306(64px·폭 74%), 흰 글자/어두운 외곽선/노란 강조. 상자·패널·단계 칩 없음. 장면마다 한국어 텍스트 위치를 올리지 않는다.

## 정확성과 완료 조건

- 이 영상은 확장형 스터드 앵커의 일반 원리. 석고보드용 토글 앵커·접착식 앵커·언더컷 앵커와 섞지 않는다.
- 너트 조임은 원뿔을 벽 깊숙이 밀어 넣는 동작이 아니라 링 안으로 바깥쪽으로 당기는 동작이다.
- 링은 원뿔 경사면에 의해 확장한다. 벽을 부풀리거나 녹이거나 나사산이 콘크리트를 파고드는 묘사 금지.
- 구멍은 시작부터 존재. 이 비교를 완전한 현장 설치 순서로 소개하지 않는다. 특정 토크·깊이·하중 수치 없음.
- 최종 음성/영상 길이 일치, 문구 누락 없음, 중앙 가독성, 전체 구조 이해, 방향/접촉/고정 상태, 무의미한 정지·카메라 드리프트를 검수한다.
- 마지막 실사용→처음 비교 막대는 구도가 이어지는 반복 편집일 뿐, 같은 고정 앵커가 저절로 풀린다는 연출 금지.
- 완성 미디어/Blender 소스/키/서명 URL은 로컬 전용. Git에는 이번 텍스트·설정·명령만.
