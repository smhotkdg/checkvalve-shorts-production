# 인덕션: 불 없이 냄비 바닥 자체를 데우는 기술

상태: 초안(2026-10-11). 대본 승인 → 필재 실측 → 스타일 프레임 4장 승인 순서로 진행합니다. TTS·Higgsfield·Blender 렌더는 아직 시작하지 않았습니다.

## 포맷: `problem_solution` (기초 → 원리 → 문제 → 해결 → 새 난관 → 추가 해결 → 실사용)

최신 레퍼런스 [41vfH3EtqOM](../../docs/references/41vfH3EtqOM-analysis.md)처럼 **기본 상태를 먼저 이해시키고, 그 상태의 문제 때문에 냄비 바닥 구조가 바뀌는 과정**을 같은 냄비 단면 위에서 보여 줍니다. 사용자 요청(2026-10-11): 인덕션의 아주 기초부터 설명해서 원리 → 문제점 → 해결 순서.

| 비트 | 내용 | 다음으로 넘어가는 이유 |
|---|---|---|
| 훅 | 불꽃·열선 없이 냄비만 끓음 + 반응어 | "어떻게?"라는 질문을 만든다 |
| 기초 1 | 전선에 전기 → 자기장 (나침반 바늘이 돈다) | 전기가 자기장을 만든다는 출발점 |
| 기초 2 | 전선을 감으면 자기장이 가운데로 모임 (코일) | 상판 아래 구리선의 정체 |
| 원리 | 방향이 수만 번 바뀌는 전기 → 냄비 바닥 소용돌이 전류 → 저항으로 발열 | 냄비 바닥 자체가 열원 |
| 문제 1 | 유리·알루미늄 냄비는 그대로 | 아무 냄비나 되는 게 아니다 |
| 해결 1 | 바닥에 자석이 붙는 금속을 덧댐 → 끓음 | 그런데 이 금속에도 한계가 있다 |
| 문제 2 | 열이 안 퍼져 코일 모양 고리만 뜨거움 | 고르게 데울 방법이 필요하다 |
| 해결 2 | 아까 쫓겨난 알루미늄을 사이에 끼움 → 고르게 퍼짐 | 앞의 실패가 해결사로 돌아오는 반전 |
| 실사용 | 여러 겹 바닥의 이유 + 자석 테스트 | 시청자가 집에서 바로 확인 |

훅 반응어: **"귀신이 곡할 노릇이죠"** (사용 이력: 제정신이 아닌, 놀라 자빠지죠, 기가 막히죠, 말도 안 되죠, 멘탈이 나가버렸습니다와 겹치지 않음).

## 한 줄 원리

상판 아래 구리 코일에 방향이 빠르게 바뀌는 교류가 흐르면 코일 가운데로 모인 자기장도 계속 바뀝니다. 이 변하는 자기장이 냄비 바닥 금속 안에 소용돌이(맴돌이) 전류를 만들고, 그 전류가 금속의 저항을 지나며 열이 됩니다. 불이나 뜨거운 판이 냄비를 데우는 것이 아니라 **냄비 바닥 자체가 열원**입니다.

- 문제 1: 유리는 전기가 통하지 않아 전류가 생기지 않습니다. 알루미늄·구리는 저항이 너무 작고 자성이 없어 일반 인덕션 주파수에서는 열이 거의 나지 않습니다.
- 해결 1: 자석이 붙는(강자성) 금속, 예: 자성 스테인리스를 바닥에 붙이면 전류가 바닥 표면에 몰리고 저항이 커져 잘 데워집니다.
- 문제 2: 이 금속은 열전도가 낮아 코일 모양을 따라 고리 모양으로 뜨거운 곳이 생기고 가운데·가장자리가 덜 데워집니다.
- 해결 2: 열을 잘 퍼뜨리는 알루미늄 층을 스테인리스 사이에 끼운 여러 겹 바닥(3중 바닥 등)으로 열을 고르게 퍼뜨립니다.

끝 정보: 냄비 바닥에 자석이 잘 붙으면 인덕션에 쓸 수 있습니다.

근거
- [Wikipedia: Induction cooking](https://en.wikipedia.org/wiki/Induction_cooking): 일반 주파수 약 25~50kHz, 맴돌이 전류의 줄열(히스테리시스는 10% 미만), 알루미늄·구리는 낮은 저항률과 비자성으로 잘 안 데워짐, 유리는 비전도체, 자성 스테인리스 + 알루미늄 심의 3중 바닥, 자석 테스트, 올메탈 인덕션 예외.
- [CENOS: The challenges of induction heating for cooktops](https://cenos-platform.com/the-challenges-of-induction-heating-for-cooktops-case-study/): 코일 형태에 따른 고르지 않은 가열(가운데가 상대적으로 덜 뜨거움), 다층 재료가 고른 가열에 도움.

## 정확성 기준

- 열은 냄비 바닥 금속 안에서 생깁니다. 유리 상판이나 코일이 빨갛게 달아오르는 장면을 넣지 않습니다. 상판이 냄비 열을 받아 따뜻해질 수는 있으므로 "상판은 차갑다"고 말하지 않습니다.
- "1초에 수만 번"은 일반 주파수 약 25~50kHz에 맞는 표현입니다. 화면에 kHz·온도·전력 숫자를 넣지 않습니다.
- 자기장선은 코일 가운데를 지나 바깥으로 돌아오는 닫힌 고리로 그리고, 냄비 바닥을 위아래로 통과하게 합니다. 전기 방향이 바뀔 때 자기장 화살표도 함께 뒤집힙니다.
- 소용돌이 전류는 냄비 바닥 평면 안에서 코일과 같은 중심의 고리로 돕니다. 냄비 벽이나 물속에는 그리지 않습니다.
- 알루미늄은 "열이 거의 안 난다"로 단순화합니다. 일부 고주파 올메탈 인덕션은 알루미늄도 데울 수 있어 설명문에 밝힙니다.
- 고리 모양 가열은 개념 그림입니다. 실제 분포는 코일·냄비마다 다릅니다. 열지도 색은 상대적 온도 표시이며 수치가 아닙니다.
- 무쇠처럼 한 겹이어도 인덕션에 쓰이는 냄비가 있습니다. "모든 인덕션 냄비는 여러 겹이어야 한다"고 말하지 않습니다.
- 자석 테스트는 "잘 붙으면 쓸 수 있다"까지만 말합니다. 약하게 붙는 냄비의 효율 차이는 다루지 않습니다.
- 특정 브랜드, 냄비 제품명, 상판 소재명을 말하지 않습니다.

## 한눈에 보이는 화면 (config `visual_clarity`)

**기본 시점 하나:** 반으로 자른 인덕션과 냄비를 비스듬한 옆에서 봅니다. 아래부터 구리 코일(납작한 나선) → 반투명 짙은 회색 유리판 → 냄비 바닥 단면 → 물. 영상의 60% 이상을 이 시점으로 보여 줍니다. 좌→우 방향은 끝까지 유지합니다.

```
        ~~~ 물 ~~~
   │███ 냄비 바닥 단면 ███│   ← 소용돌이 전류(청록 점선) → 열(주황~빨강)
 ════════ 유리판(반투명) ════════
   ◎◎◎◎◎  구리 코일  ◎◎◎◎◎      ← 자기장 고리(하늘색)가 가운데로 올라감
```

**보조 시점 (최대 3개, 각 3초 이내 후 기본 시점 복귀)**
1. 기초 무대: 밝은 바닥 위 곧은 전선 한 가닥과 작은 나침반 하나. 전선이 그대로 둥글게 말려 코일이 되며 기본 시점의 코일 위치로 이어집니다.
2. 냄비 바닥 위에서 내려다본 열지도: 고리 모양으로 뜨거운 문제 상태 → 고르게 퍼진 해결 상태.
3. 바닥 층 분해: 스테인리스 / 알루미늄 / 자석 금속 세 겹이 옆으로 살짝 벌어졌다 합쳐짐.

**색으로 의미 구분 (주제 예외 기록)**

| 대상 | 색 | 의미 |
|---|---|---|
| 열 (냄비 바닥 열지도) | 회색 → 주황(#FF7A1A) → 빨강 | 주인공. 시청자가 따라갈 하나 |
| 자기장 고리 | 반투명 하늘색 선 3~4개 + 화살촉 | 방향이 바뀌면 화살촉이 뒤집힘 |
| 전류 (전선·코일·소용돌이) | 흰빛 청록 점이 흐름 | 전기가 흐르는 곳 |
| 구리 코일 | 채도 낮은 무광 구리색 | 고정 부품 |
| 유리판 | 반투명 짙은 회색 | 고정 |
| 냄비 재질 | 유리 투명 / 알루미늄 밝은 은색 / 자석 금속 짙은 철회색 / 스테인리스 연회색 | 재질 구분 |
| 배경 | 부드러운 밝은 그라데이션과 평평한 바닥 | 주방 소품 없음 |

대사에서 부품(구리선, 냄비 바닥, 자석이 붙는 금속, 알루미늄)을 처음 말할 때 그 부품에 노란(#FFD400) 테두리 빛을 약 1.5초 줍니다. 이름표 글자는 넣지 않습니다.

**시청자가 따라갈 하나:** 냄비 바닥의 열 색. 데워지지 않으면 회색, 고리만 뜨거우면 빨간 고리, 해결되면 바닥 전체가 고른 주황.

**뺄 것:** 조작 버튼·디스플레이, 냉각팬, 회로 기판, 전선 다발, 손잡이 디테일, 불꽃, 연기, 파티클 효과(김은 작은 물방울 기포 몇 개만), 어두운 조명, 주방 배경 소품, 숫자.

## 스타일 프레임 승인 (렌더 전)

1. 기초 무대: 곧은 전선 둘레의 하늘색 자기장 고리와 옆에서 돌아간 나침반 바늘
2. 기본 단면 시점: 코일 위 자기장이 냄비 바닥을 통과하고 바닥에 청록 소용돌이 + 주황 열
3. 위에서 본 열지도: 빨간 고리만 뜨겁고 가운데·가장자리는 회색인 문제 상태
4. 바닥 층 분해: 세 겹 사이로 알루미늄이 끼워지며 열이 고르게 퍼진 순간
