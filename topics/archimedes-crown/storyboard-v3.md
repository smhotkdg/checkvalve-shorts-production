# 왕관 쇼츠: 동작과 수위 변화 중심 콘티 v3

2026-10-11 사용자 피드백: 이전 기준 이미지는 정적이고 물의 양 변화가 작다. 이미지부터 늘리지 않고 이야기·동작·전후 상태를 먼저 확정한다. 이전 image-first-v2 장면 계획은 검토 이력으로 남기고 이번 v3를 우선한다. 유료 영상 제출은 콘티 이미지 확인 전 보류한다.

## 전달할 내용

왕관을 훼손할 수 없다 → 같은 무게를 재도 순금인지 구별되지 않는다 → 물에 넣어 금속의 부피를 비교한다 → 같은 무게지만 왕관이 더 많은 물을 밀어내면 순금과 조성이 다를 수 있다. 금·은 합금을 가정한 설명이다. 아르키메데스의 왕관은 후대에 전해진 일화이며, 현대 투명 용기를 쓰는 원리 재현이다.

## 시각적 인과관계

- 정지 상태를 카메라 줌으로 늘리지 않는다. 물체의 이동·접촉·침수·인양을 보여준다. 측정 결과를 읽는 짧은 정지 구간은 필요하다.
- 같은 왕관, 순금 왼쪽/왕관 오른쪽, 같은 컵 크기와 초기 물의 양. 저울→물통으로 물체가 이동하는 경로를 보여준다.
- 비교 컵은 낮고 넓어 왕관 전체가 들어간다. 초기 수면은 컵 높이 약 35%, 설명용 결과 수면은 왼쪽 약 50%/오른쪽 약 75%로 시각 차이를 크게 그린다. 이 비율은 실제 물리 계산값이 아닌 과장된 콘티 기준이다. 정확한 용적 비율이나 금 함량으로 읽히는 숫자는 화면에 쓰지 않는다.
- 물이 올라오는 순간이 핵심이다. 빈 컵이나 정지 결과만 건너뛰어 보여주지 않는다. 물체가 수면에 닿기 전에는 수위가 올라가지 않는다. 완전히 잠긴 뒤에는 더 내려가거나 회전해도 수위가 계속 오르지 않는다.
- 잔물결·작은 물보라·금속 흔들림은 동작의 결과로 생긴다. 왕관 가운데는 물이 채우며, 왕관 안에 공기 주머니나 불투명 물판을 넣지 않는다. 컵 밖으로 넘치는 연출은 이번 수위 비교 방식에서 쓰지 않는다.
- 왕관·순금·수면을 가리는 큰 물보라, 화면을 채우는 왕관 확대, 좌우 반전, 늘어나는 왕관, 갑자기 생기는 복제 물체를 금지한다.

## 이미지 제작과 검수

총 10장, 각 장면의 동작을 가장 잘 보여주는 순간을 개별 이미지로 만든다. 여러 장이 사실상 같은 정물 사진이 되지 않도록 주인공의 높이·위치·기울기와 접촉 전후를 바꾼다. 같은 황금 왕관·올리브 잎 양각·린넨·청동·석회암·따뜻한 부드러운 조명을 유지한다. 물은 투명하되 수면 경계를 선명하게 보여준다.

글자는 원본에 생성하지 않는다. 제목 중심 y=260/자막 중심 y=1306, 크기·폭·두 줄 규칙은 전역 layout v5 그대로다. 액션은 주로 화면 y=32–63%에 모으고 제목/자막을 가리지 않는다. 콘티 이미지에 화살표나 별도 라벨을 넣어 최종 영상으로 흘러들게 하지 않는다.
