# 왕관 영상 2차: 이미지 10장 우선 제작

현재는 검토 이력: 사용자 피드백에 따라 정적인 장면과 작은 수위 차이를 수정한다. 최신 제작 기준은 storyboard-v3.md다. v2 이미지를 사용한 유료 영상은 아직 제출하지 않았다.

2026-10-11 사용자 요청: 같은 주제의 레퍼런스 이미지 10장을 먼저 만들고, 그 이미지를 기반으로 영상을 제작한다. 기존 완성 파일은 보존하고 v2로 저장한다.

공통: 승인된 금빛 올리브 잎 왕관·청동·석회암·린넨·따뜻한 조명을 유지한다. 비교 장면은 순금 왼쪽, 왕관 오른쪽. 실제 이미지에 글자를 굽지 않고 최종 합성에서 전역 layout v5를 읽는다. Typecast 필재 한글 대본과 실측 음성은 재사용한다.

| 장면 | 타임라인(초) | 기준 이미지와 주요 동작 |
|---|---|---|
| 01 | 0–2.89 | 린넨 위 온전한 왕관, 작은 재질 반사와 천 움직임 |
| 02 | 2.89–6.95 | 사용하지 않는 도가니·집게, 같은 왕관 옆 순금 |
| 03 | 6.95–9.57 | 저울 왼쪽 순금/오른쪽 왕관, 흔들림 감소 |
| 04 | 9.57–13.45 | 수평 저울과 두 물체, 같은 무게 |
| 05 | 13.45–16.51 | 저울에서 두 물체를 들어 용기로 이동 |
| 06 | 16.51–19.31 | 동일 용기·동일 초기 물, 물체는 수면 위 |
| 07 | 19.31–23.79 | 접근→접촉→침수 순서, 접촉 후 수위 상승 |
| 08 | 23.79–31.89 | 완전 침수, 왕관 쪽 수위가 높음, 잔물결 |
| 09 | 31.89–38.05 | 열린 왕관 가운데 물을 관찰, 완전 침수 중 수위 일정 |
| 10 | 38.05–44 | 훼손 없이 인양, 왕관을 린넨에 내려놓음 |

이미지는 로컬 work/archimedes-crown/image-first-v2/에 보관한다. 각 이미지를 개별 생성하고 실제 화면을 검토한 뒤 해당 장면의 시작 이미지로 사용한다. 맞지 않는 이미지는 수정 후 사용한다. 단순 정지 이미지 줌 합성으로 완료하지 않는다. 영상에서도 전체 기구가 보이는 작은 물체 동작과 부드러운 연결을 유지한다.

물리 가드: 열린 왕관의 빈 공간은 물로 채워진다. 금속 자체의 부피를 비교한다. 완전 침수 후 물체를 회전해도 밀어낸 물의 양은 변하지 않는다. 수위 차이는 설명용 확대이며 정량 순도 검사나 검증된 고대 실측 장비 재현이 아니다.

진행 상태: 장면별 이미지 생성 중. 기존 outputs/archimedes-crown-final.mp4는 이전 완료 버전이다. v2가 실제 생성·합성·검수되기 전에는 완료로 보고하지 않는다.
