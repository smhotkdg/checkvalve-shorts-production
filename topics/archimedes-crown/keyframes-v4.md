# 왕관 콘티 단일 장면 입력 — Higgsfield v4

스타일 기준은 승인된 5열×2행의 10장면 콘티다. 세로 9:16 단일 장면, 따뜻한 아이보리 배경, 부드러운 석회암·린넨 질감, 잉크 외곽선과 입체적으로 음영 처리된 금/청동. 올리브 잎 양각의 낮고 열린 금빛 왕관을 유지한다. 왕관에 보석·높은 뾰족 장식·은 단면을 추가하지 않는다. 같은 불규칙 순금 덩어리를 사용한다.

원본 이미지와 생성 클립에는 글자를 넣지 않는다. 콘티의 숫자·화살표·점선 이전 위치·붉은 X·여러 시점의 물체를 복제하지 않는다. 실제 상태만 하나씩 그린다. 위쪽 제목과 아래쪽 자막을 위한 여백을 두며, 전체 장치와 두 수면을 중간 거리에서 볼 수 있어야 한다. 강한 확대는 없다.

Higgsfield 모델의 초 단위 동작 지시가 그대로 실행된다고 가정하지 않는다. 실제 결과에서 착지·물 접촉·수평·완전 침수·인양 시각을 확인하고, 확인한 동작 구간을 필재의 실제 단어 시각에 맞춰 편집한다. 말소리의 속도와 원문은 바꾸지 않는다.

물통/린넨 구도는 최종 영상에서 90px 위로 옮겨 두 줄 자막과 겹치지 않게 했다. 위의 빈 배경만 프레임 밖으로 나가며 장치 전체는 남는다. 아래 배경은 기존 가장자리로 이어 붙인다. 저울은 고정 제목과 꼭대기 장식이 겹치지 않도록 이동 중 구도만 부드럽게 조정한다. 텍스트 좌표는 모든 장면에서 동일한 공통 v6이다.
