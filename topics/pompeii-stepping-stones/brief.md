# 폼페이의 디딤돌

이집트 영상에서 승인받은 따뜻한 질감·음영 있는 잉크 일러스트와 원본 필재 한국어, layout v6을 유지한다. 다음 제작 입력은 storyboard-v1.md, narration.txt, captions-ko.json, topic.json이다. 현재는 콘티 초안 단계이며 완성 영상이 아니다.

관객의 질문은 ‘길 한가운데 왜 큰 돌을?’ → ‘젖는 발을 피하려고’ → ‘그럼 수레는?’ → ‘틈으로 바퀴가 지나간다’ 순서다. 물 흐름과 사람의 이동, 단면, 평면도, 바퀴 통과로 화면의 목적을 바꾼다. 도시 파괴/전쟁 대신 일상 문제를 해결하는 도로를 보여준다.

50크레딧은 상한이며 목표가 아니다. 현재 5초 무음 Standard 클립 2개 견적 합계 12.5크레딧. 필요한 인물 동작만 생성하고 물·돌·수레의 정확한 경로는 같은 질감의 로컬 애니메이션으로 제작한다. 현재 유료 생성/TTS 제출 없음. 영상 생성 직전에 견적을 다시 확인한다.

콘티 이미지의 보도 높이와 돌의 긴 축은 두 번째 이미지 편집에서 바로잡았다. 기본 제공 이미지 생성 도구를 사용했고, 최초/수정 프롬프트를 각각 보관했다. 최종 콘티는 로컬 work/pompeii-stepping-stones/storyboard-v1/storyboard-10-scenes.png에 있다. 이미지·영상·제작 코드·키는 Git에 업로드하지 않는다.

역사 사실 및 그림의 한계는 storyboard-v1.md의 근거/정확성 항목을 따른다. 3개 돌은 하나의 설명용 배치이며 모든 폼페이 도로/수레를 대변하지 않는다.
