# 폼페이 — 길 한가운데 거대한 돌을 놓은 이유

현재 상태: 10장면 콘티 초안. 유료 영상/TTS 생성 전. 승인받은 이집트 영상의 그림체·질감·전역 layout v6을 유지한다. 한 장의 콘티 이미지는 기본 제공 이미지 생성 도구로 생성했고, 04 보도 높이/07 돌의 긴 축을 이미지 편집으로 교정했다. 최종 로컬 파일: work/pompeii-stepping-stones/storyboard-v1/storyboard-10-scenes.png. 최초/수정 프롬프트는 이 폴더의 .prompt.txt 파일을 따른다.

## 이야기의 흐름

길을 막은 것처럼 보이는 돌 → 물이 흐르는 차도와 젖는 발 → 높은 디딤돌로 건너기 → 새로운 의문 ‘수레는?’ → 돌 사이의 틈으로 바퀴 통과 → 사람·물·수레가 같은 길을 쓰는 장면으로 회수.

기존 문제에 해결을 더하고, 그 해결이 만든 것처럼 보이는 새 난관을 다시 푼다. 실제 도로의 역사 전체를 단일 발명 사건으로 꾸미지 않는다.

초안 약 43초. 필재 발화 측정 후 장면 길이를 맞추며 음성을 빨리 읽거나 자르지 않는다. 생성한 5초 동작의 끝에서 인물이 멈추는 구간이 필요하면 물 흐름/잔물결을 유지하며 마무리한다. 장면이 바뀔 때는 별도의 공간/관측 정보가 추가되어야 하며, 10개 똑같은 도로 그림을 줌으로 바꾸지 않는다.

## 정확한 통과 구조

- 도로는 영상/도면에서 세로 방향, 디딤돌 3개는 가로로 나란히 배치한다. 각 돌의 긴 축은 도로 길이 방향이다.
- 돌은 발을 올리는 보도 정도 높이의 둥근 모서리 현무암 덩어리다. 제목의 ‘거대한’은 눈에 띄는 큰 돌이라는 표현이지 사람보다 큰 바위가 아니다.
- 두 바퀴의 중심 경로가 돌 사이의 두 내부 틈과 일치한다. 바퀴는 차도 바닥에 있고 돌을 타고 올라가지 않는다.
- 중앙 돌은 수레 몸통 아래를 지나며 차축/몸통과 겹치지 않는다. 도면의 비율은 원리 설명이며 실측 복원 모델이 아니다.
- 수레 통과의 원리는 일관된 질감의 직접 애니메이션으로 제작한다. AI에 돌 사이를 통과시키도록 반복 요청해 비용을 늘리지 않는다.
- 사람은 돌 위로, 물은 틈으로. 물은 얕게 표현하며 돌 윗면까지 잠기지 않는다. ‘도로 전체가 늘 똥물이었다’는 과장이나 지하하수도가 전혀 없었다는 설명은 하지 않는다.

## 화면과 소리

전역 layout v6 필수: 제목 중심 (540,260), 설명 중심 (540,1360), 설명 64px·최대 2줄·의미별 선개행. 제목은 ‘길 한가운데 돌을 / 놓은 진짜 이유’. 흰색/노란색·검은 외곽선, 배경 패널·추가 진행 칩 없음. 콘티의 장면명/화살표는 설명용이며 최종 영상에서 필요한 동작 화살표 외 장면명은 제거한다.

원본 Typecast 필재 한국어만 사용한다. 물 흐름, 샌들 걸음, 나무/바퀴 소리와 작은 전환 효과음을 설명에 맞춰 낮게 넣는다. 배경음으로 말을 가리지 않는다. 극단적 줌을 피하고 전체 도로-돌-바퀴 관계를 보존한다.

## 비용 계획

현재 조회된 Kling 3.0 Standard·무음·9:16·5초 견적 6.25크레딧 × **2개 = 12.5크레딧**. 사람의 발 반응/돌 위 걷기에만 사용한다. 나머지는 같은 그림체의 재사용 자산과 직접 움직이는 설명으로 구성한다. 품질 검수에서 꼭 필요한 동작이 빠졌을 때만 1개를 추가하면 18.75크레딧이다. 50은 상한이며 목표 지출이 아니다. 실제 생성 직전에 같은 파라미터 견적을 다시 조회한다. 현재 영상 작업은 제출하지 않았으므로 사용량은 0이다. Typecast와 기본 이미지 생성은 Higgsfield 영상 크레딧과 별도로 취급한다.
