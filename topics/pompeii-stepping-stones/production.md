# 폼페이 디딤돌 — 제작 v1

제작 및 검수 완료. 최신 요청은 **모든 장면에 설명과 연결된 실제 움직임**을 넣는 것이다. 인물 클립 2개만 생성한다는 초기 표현은 전체 영상이 2장면만 움직인다는 의미가 아니었지만, 실제 제작에서는 도시의 수레 접근/마무리 동작까지 보강해 총 4개 클립으로 6장면을 구성한다. 나머지 4장면은 물·수레·바퀴·높이 시연을 직접 애니메이션으로 만든다. 정지 이미지의 확대/이동만으로 장면을 채우지 않는다.

## 결과와 비용

45초·1080×1920·24fps·한국어, 원본 Typecast 필재. 음성은 음높이를 유지한 0.94배 속도, 전체 오디오 43.562초/마지막 발화 약 43.13초이며 45초 화면에 맞춘다. 자막은 원래 대본 문구를 보존한 21개 의미 단위다. ASR은 시간 측정 용도로 쓰고 인식 오타를 자막에 복사하지 않는다.

Higgsfield 무음 Kling 3.0 Standard 5초 클립 4개, 개당 6.25크레딧으로 **실제 25크레딧** 사용했다. 견적 합계와 잔액 차이로 확인했다. 초기 12.5크레딧 계획은 이번 전 장면 동작 요청을 반영해 수정했다. 재생성/추가 유료 이미지/업스케일/오디오/렌더는 실행하지 않았다. 50은 상한이며 목표 지출이 아니다. 이전 이집트 영상 42.5크레딧보다 17.5크레딧 적게 사용했다. Typecast 대본 301자는 별도 사용량이다. 앞으로 재제작할 때는 같은 파라미터라도 현 시점의 견적을 다시 확인한다.

## 장면과 동작

| 장면 | 동작 | 원본 |
|---|---|---|
| 01 길 한가운데 돌 | 수레 접근, 안내 인물 걸음, 배수 | 클립 01의 0~2.4초 |
| 02 발밑의 문제 | 여성이 발밑을 보고 망설임, 물 흐름 | 클립 03의 0~2.4초 |
| 03 젖기 싫은 발 | 발을 거두는 반응, 흐르는 물 | 클립 03의 2.4~5초 |
| 04 보도 높이의 돌 | 같은 높이를 따라가는 시연 표시와 얕은 물 | 직접 애니메이션 |
| 05 돌을 밟고 건너기 | 실제 디딤돌 발 접촉과 반대편 보도로 걷기 | 클립 05 |
| 06 수레는 어떻게? | 수레의 나머지 접근과 회전하는 바퀴 | 클립 01의 2.4~5초 |
| 07 틈을 내려다보면 | 평면도로 접근하는 수레와 두 바퀴 경로 | 직접 애니메이션 |
| 08 바퀴는 돌 사이로 | 전체 수레 이동, 바퀴 회전, 중앙 돌 위의 차축 여유 | 직접 애니메이션 |
| 09 물도 계속 흐른다 | 통과 후 움직이는 수레, 틈 사이 배수 | 직접 애니메이션 |
| 10 사람·물·바퀴의 길 | 맞은편 보도에서 걷는 사람과 멀어지는 수레 | 클립 10 |

클립을 반복 재생하지 않고 서로 겹치지 않는 구간으로 나눠 연결한다. 화면 길이를 필재 음성에 맞춰 조정하며 발화를 자르거나 빨리 읽게 하지 않는다. 직접 애니메이션의 돌/보도는 고정하고 바퀴 이동 경로와 차축 높이는 장면 07~09에서 유지한다. 형상을 움직이게 하기 위해 돌을 흔들거나 결과를 바꾸지 않는다.

최종 제목/자막 중심은 전역 layout v6의 (540,260)/(540,1360)이다. 설명 64px·최대 2줄·의미별 선개행, 흰색/노란색과 검은 외곽선, 패널 없음. 물 흐름·샌들·나무/바퀴 효과음을 낮게 섞고 음성을 우선한다.

## 설정·환경·명령

생성 이미지/영상 프롬프트, 클립 분할, 직접 애니메이션의 위치/크기/차축 여유는 production-v1.json에 있다. Python(Pillow, NumPy), FFmpeg/FFprobe, Noto Sans KR 폰트를 사용한다. Typecast 원본 필재는 인증된 카탈로그에서 다시 찾으며 대체 음성은 허용하지 않는다. 키는 기존 사용자 암호화 파일을 사용하고 Git에 넣지 않는다. 다른 PC에서는 Typecast 키와 Higgsfield 연결을 새로 설정한다.

```powershell
.\scripts\connect-typecast.ps1 -GenerateNarration -ScriptPath .\topics\pompeii-stepping-stones\narration.txt -OutputPath .\work\pompeii-stepping-stones\production-v1\piljae-raw.wav
.\scripts\validate-layout.ps1
ffprobe -v error -show_streams -show_format -of json .\outputs\pompeii-stepping-stones-final.mp4
ffmpeg -v error -i .\outputs\pompeii-stepping-stones-final.mp4 -map 0:v -map 0:a -f null -
```

사용자 요청에 따라 직접 렌더/편집 소스는 로컬 work/에 보관한다. 이 명령들은 연결/검수용이며 새 PC에서 전체 영상을 자동 재생성하는 단일 명령이 아니다. 다른 작업자에게 위 생성 프롬프트/기하 설정/장면 동작/전역 텍스트 규칙을 전달해 같은 프로세스를 적용한다. 미디어·작업 코드·업로드 주소·API 키는 공개 Git에서 제외한다.

완성 경로는 outputs/pompeii-stepping-stones-final.mp4, 자막은 outputs/pompeii-stepping-stones.srt, 검수는 outputs/pompeii-stepping-stones-verification.json이다.

## 역사적 정확성

스토리의 근거는 storyboard-v1.md에 있는 고고학 연구다. 도로 배수·보행 디딤돌·바퀴가 지나갈 틈은 자료에 근거하며, 인물·정확한 도시 배치·수레 모델은 설명용 재구성이다. 직접 시연의 길이/높이는 실측 모델이 아니다. 모든 로마 수레의 폭 표준화, 현대 철도 궤간과의 연결, 현대 횡단보도의 직접 기원은 주장하지 않는다. 실제 도시 장면의 차량과 설명용 두 바퀴 모델이 모든 역사적 차량 유형을 대변하지 않는다.

## 완료 검수

1080×1920·24fps·45.000초·1080프레임, H.264/AAC 전체 디코딩 통과. 자막 21개는 원문 문구와 일치하며 제목/설명 중심과 최대 2줄·안전 영역을 검사했다. ASR 유사도는 약 0.976이며 시간 측정에만 사용했다. 모든 장면의 자막 밖 영역에서 움직임 샘플을 확인했고, 두 내부 틈과 바퀴 폭/차축 높이의 기하 검사를 통과했다. 인코딩 장면과 9:16/9:19.5/9:20 화면 시뮬레이션을 검토했다. 원리 장면은 실측 복원이 아닌 설명용 도해다.
