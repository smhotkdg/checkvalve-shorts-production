# 이집트 젖은 모래 — 제작 v1

승인된 10장면 콘티 v2를 43초·1080×1920·24fps 한국어 영상으로 제작한다. 전체 이동은 석상 운반 → 마른 모래의 저항 → 물 붓기 → 이동 → 원리 비교 → 벽화 → 목적지 도착이다. 같은 풍경을 반복하기보다 시점과 설명 대상을 바꾼다.

## 비용과 생성 규칙

이번 Higgsfield 실제 사용량은 **42.5크레딧**, 상한은 **50크레딧**이다. 7.5크레딧 예비분은 사용하지 않았다. 제출 전 확인한 견적 합계와 계정 잔액 변화가 일치했다. Typecast 사용량은 별도이며 한국어 대본 311자다. 다음 제작에서는 현재 견적을 다시 조회한다.

별도 Higgsfield 이미지·업스케일·음성·렌더 생성은 실행하지 않는다. 실패·재시도까지 비용에 포함하며, 결과가 불명확한 요청을 자동 재제출하지 않는다. 재생성이 필요하면 견적을 확인하고 총합 50 이하에서만 진행한다. 모든 이미지와 투명 썰매 자산은 기본 제공 이미지 생성 도구에서 준비하고 로컬에 저장한다.

## 재제작 입력과 순서

1. `storyboard-v2.md`, `narration-v2.txt`, `captions-ko.json`, `production-v1.json`을 함께 읽는다. production-v1.json에 실제 영상/시작 이미지 프롬프트와 모델 설정이 있다.
2. 같은 석상·줄무늬 머리 장식·밧줄·나무 썰매·흰 리넨을 유지한 시작 이미지를 만든다. 주요 물체는 제목/자막 영역과 겹치지 않도록 배치한다.
3. 04 물 붓기를 먼저 생성·확인한 후 나머지 5개 클립을 생성한다. 사람 동작과 물줄기 장면은 Pro, 넓은 운반·도착은 Standard를 사용한다. 화면비 9:16, 생성 음성은 끈다.
4. Typecast 인증 카탈로그에서 **원본 필재**를 확인하고 대본을 생성한다. 같은 이름의 다른 화자나 자동 대체 음성은 사용하지 않는다.
5. 음성에 맞춰 아래 프레임 수로 장면을 연결한다. 영상 속도만 장면 길이에 맞추며 설명을 자르지 않는다. 장면 06은 손 모양을 유지하는 첫 3.7초를 사용한다.
6. 모래 흐름, 모래알 접촉점의 작은 물 다리, 동일 썰매의 적정/과습 비교, 벽화 인물 강조를 로컬에서 움직인다. 과습 비교 이동량은 원리 시연이며 실측 수치가 아니다.
7. layout v6의 고정 제목 중심 (540,260), 설명 중심 (540,1360)을 유지한다. 설명은 64px, 최대 2줄, 의미 단위 개행, 흰색/노란색·두꺼운 검은 외곽선, 패널 없음이다. 영상 속 인물이 겹치면 영상을 재배치하고 자막을 위로 이동하지 않는다.
8. 줄 당김·모래·물·전환 효과음을 낮은 음량으로 넣고 필재 음성을 우선한다. 최종 H.264/AAC 영상에 자막을 픽셀로 합성한다.

## 환경 및 명령

Typecast 키는 기존 Windows 연결 스크립트의 숨김 입력/사용자 암호화 저장을 사용한다. Higgsfield는 연결된 계정이 필요하다. 키, 업로드 서명 URL, 생성 결과 주소를 설정 파일이나 Git에 넣지 않는다. Typecast 연결은 별도 PC에서 다시 설정한다.

```powershell
# 대본 TTS 생성 (기존 연결 스크립트, 카탈로그에서 원본 필재 확인)
.\scripts\connect-typecast.ps1 -GenerateNarration -ScriptPath .\topics\egypt-wet-sand\narration-v2.txt -OutputPath .\work\egypt-wet-sand\production-v1\piljae-raw.wav

# 전역 텍스트 배치 규칙 검사
.\scripts\validate-layout.ps1

# 로컬 최종 파일 정보/전체 디코딩 검사
ffprobe -v error -show_streams -show_format -of json .\outputs\egypt-wet-sand-final.mp4
ffmpeg -v error -i .\outputs\egypt-wet-sand-final.mp4 -map 0:v -map 0:a -f null -
```

제작에는 Python(Pillow, NumPy), FFmpeg/FFprobe, 한국어 Noto Sans 폰트와 로컬 음성 시간 측정을 사용했다. 사용자 요청에 따라 제작 코드와 미디어는 Git에 포함하지 않는다. 위 명령은 기존 연결 및 검수 명령이며, 전체 영상이 자동 재생성되는 단일 명령은 아니다. 이 텍스트와 설정을 다른 작업자에게 전달해 같은 생성/편집 순서를 적용한다.

완성 파일은 `outputs/egypt-wet-sand-final.mp4`, 자막은 `outputs/egypt-wet-sand.srt`, 검수 기록은 `outputs/egypt-wet-sand-verification.json`이다. 로컬 전용 파일이며 공개 저장소에는 업로드하지 않는다.

## 정확성

제후티호테프 벽화의 물 붓는 인물과 현대 젖은 모래 실험을 바탕으로 구성했다. 배경 장소·인원·도착 장면·벽화 그림은 설명용 재구성이다. 피라미드 전체 건설 방식이 증명됐다고 말하지 않는다. 물이 석상을 띄우는 윤활막처럼 표현하지 않는다.
