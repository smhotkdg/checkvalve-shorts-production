# 거대한 석상을 움직인 물 한 항아리

상태: 텍스트 콘티 및 한 장짜리 이미지 초안. 영상/TTS 생성 전.

## 제작 방향

- 고대 이집트의 석상 운반을 설명하는 10장면. 길이는 약 55~60초 기획치이며 필재 음성을 실제 측정한 뒤 확정한다.
- 이전 왕관 콘티와 같은 따뜻한 아이보리 배경, 잉크 선, 입체적인 재질 음영. 석회암·나무·밧줄·린넨·모래·항아리 질감을 유지한다.
- 같은 석상, 나무 썰매, 당기는 인물 3명, 물을 붓는 인물 1명을 유지한다. 인원은 설명을 위한 축약이며 실제 운반 인원 재현이 아니다.
- 진행 방향은 화면 오른쪽. 장비 전체를 보여주고 과도한 확대를 피한다. 설명 확대창을 쓸 때도 본 장면의 이동을 유지한다.
- 영상의 제목/설명 자막은 config/higgsfield-typecast.json의 전역 layout v6을 반드시 상속한다. 제목 중심 (540,260), 설명 중심 (540,1360), 설명 최대 2줄, 의미 단위 사전 줄바꿈. 콘티 이미지에서는 장면명만 프레임 밖에 표기한다.
- 이미지: work/egypt-wet-sand/storyboard-v1/storyboard-10-scenes.png (로컬 전용).
- 이후 제작 시 이 콘티를 키프레임으로 구체화하고 Higgsfield 장면 연결 + Typecast 원본 필재 음성으로 진행한다. 현재 요청은 콘티까지다.

## 텍스트 콘티

| 장면 | 화면과 움직임 | 내레이션 | 설명 자막 줄바꿈 초안 |
|---|---|---|---|
| 01 힘껏 당기기 | 사람들이 몸을 기울여 밧줄을 당기지만 썰매가 조금씩만 움직인다. | 거대한 석상을 끌던 사람들은 멘탈이 나갈 만했습니다. | 거대한 석상을 끌던 사람들은 / 멘탈이 나갈 만했습니다 |
| 02 나무 썰매 | 석상을 실은 나무 썰매와 밧줄을 한눈에 보여준다. | 석상을 나무 썰매에 싣고, 밧줄로 끌었는데요. | 석상을 나무 썰매에 싣고 / 밧줄로 끌었는데요 |
| 03 모래가 막는다 | 진행 방향 앞쪽에 마른 모래가 둔덕처럼 쌓인다. | 마른 모래가 앞에 쌓이면서, 움직임을 방해한 겁니다. | 마른 모래가 앞에 쌓이면서 / 움직임을 방해한 겁니다 |
| 04 당겨도 버겁다 | 당기는 발이 약간 미끄러지고 밧줄이 팽팽해진다. 석상은 넘어지지 않는다. | 힘껏 당겨도, 썰매는 모래더미를 밀어야 했죠. | 힘껏 당겨도 / 썰매는 모래더미를 밀어야 했죠 |
| 05 물을 붓는다 | 항아리의 물줄기가 썰매 바로 앞의 모래를 적신다. | 그런데 썰매 앞에 물을 부으면 어떨까요? | 그런데 썰매 앞에 / 물을 부으면 어떨까요? |
| 06 적당히 적신다 | 물이 스며들며 좁은 모래 길의 색이 짙어진다. 큰 웅덩이는 만들지 않는다. | 물바다로 만드는 게 아니라, 모래를 적당히 적시는 겁니다. | 물바다로 만드는 게 아니라 / 모래를 적당히 적시는 겁니다 |
| 07 모래알의 변화 | 이동을 유지하며 작은 확대창에 물로 연결된 모래알을 보여준다. | 물이 모래알 사이를 연결해, 바닥을 더 단단하게 만들죠. | 물이 모래알 사이를 연결해 / 바닥을 더 단단하게 만들죠 |
| 08 움직임이 달라진다 | 큰 앞쪽 모래더미가 생기지 않고 같은 썰매가 수월하게 전진한다. | 그러면 앞에 모래가 덜 쌓여, 같은 석상을 더 쉽게 끌 수 있습니다. | 그러면 앞에 모래가 덜 쌓여 / 같은 석상을 더 쉽게 끌 수 있습니다 |
| 09 벽화 속 단서 | 이동 화면 옆에 물을 붓는 인물이 있는 벽화 재구성을 작게 띄운다. | 실제 이집트 벽화에도, 썰매 앞에 물을 붓는 사람이 등장합니다. | 실제 이집트 벽화에도 / 썰매 앞에 물을 붓는 사람이 등장합니다 |
| 10 해결과 마무리 | 석상과 사람들이 앞으로 나아간다. 이전 상태로 되감지 않는다. | 거대한 석상을 움직이는 힌트는, 발밑의 모래에 있었던 겁니다. | 거대한 석상을 움직이는 힌트는 / 발밑의 모래에 있었던 겁니다 |

자막은 실제 TTS 타이밍에 따라 더 짧은 의미 단위로 나눌 수 있으며, 자동 글자 수 개행을 사용하지 않는다.

## 정확성

- 제후티호테프 무덤 벽화에 썰매로 석상을 운반하며 앞에 물을 붓는 인물이 표현되어 있다.
- 현대 실험에서는 적절한 수분이 모래알 사이에 물 다리를 만들어 모래를 단단하게 하고 앞쪽 모래 누적을 줄였다.
- 실제 벽화 장면의 의도와 적용 범위는 해석이 개입한다. 피라미드 전체 건설법이 입증되었다고 말하지 않는다.
- 물을 많이 부을수록 언제나 좋아진다고 설명하지 않는다. 물이나 기름이 윤활막을 만들어 썰매를 띄우는 것으로 표현하지 않는다.
- 첫 장면의 감정, 실패 동작, 마지막 이동은 설명용 재구성이다. 3명의 작업자가 실제 거대 석상을 운반했다는 주장도 하지 않는다.
- 연구에서 필요한 힘이 크게 감소했지만 콘티에서는 수치나 작업 인원 절반을 보편적인 역사 사실처럼 표현하지 않는다.

## 효과 초안

- 01~04: 밧줄 긴장, 모래 긁힘, 발 미끄러짐. 내레이션을 가리지 않는 작은 소리.
- 05~06: 항아리 물줄기와 모래에 스며드는 소리.
- 07: 작은 확대창 등장 효과. 거대한 확대/과도한 번쩍임 없음.
- 08~10: 안정적인 썰매 이동음. 해결 순간에만 짧은 강조음.

## 생성 방식

콘티 이미지는 기본 제공 이미지 생성 도구 사용. 최종 프롬프트는 같은 폴더의 storyboard-v1.prompt.txt에 기록한다. 생성 미디어는 work 아래에 보관하며 Git에 추가하지 않는다.
