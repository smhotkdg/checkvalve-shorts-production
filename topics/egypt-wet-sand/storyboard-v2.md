# 왜 석상 앞에 물을 부었을까?

상태: 10장면 텍스트/이미지 콘티 v2. v1은 반복적인 같은 측면 구도로 사용자에게 지적받았으며, 현재 채택 대상은 v2다. 영상 및 TTS는 아직 생성하지 않는다.

## 수정 방향

화면을 조금씩 움직이는 반복 구성이 아니라 운반 규모 → 사람의 노력 → 모래의 저항 → 물 투입 → 움직임 변화 → 익숙한 비유 → 내부 원리 → 물의 양이라는 두 번째 조건 → 벽화 근거 → 도착 순서로 전개한다. 설명마다 화면의 역할도 바꾼다.

따뜻한 아이보리/잉크 선/입체적인 재질 음영은 유지한다. 역사 장면에서는 같은 석상과 썰매를 유지하고, 설명 장면에서만 손 시연·모래알 그림·작은 비교 실험으로 전환한다. 갑작스러운 극단적 줌으로 전체를 잃지 않는다.

영상은 전역 layout v6 필수: 제목 중심 (540,260), 설명 중심 (540,1360), 설명 최대 2줄, 의미 단위로 미리 개행. 콘티에서는 장면명을 프레임 밖에 표기한다.

## 콘티와 내레이션

| 장면 | 화면 | 내레이션 |
|---|---|---|
| 01 운반의 규모 | 높은 시점의 넓은 운반 현장. 거대한 석상, 작은 사람들, 멀리 보이는 목적지. | 이집트 사람들은 이 거대한 석상을 어떻게 옮겼을까요? |
| 02 사람은 당기는데 | 당기는 사람 앞에서 밧줄을 따라 뒤쪽 석상을 본다. 긴장한 줄과 힘주는 동작. | 썰매에 싣고 당겼지만, 모래 위에서는 만만하지 않았습니다. |
| 03 발밑의 문제 | 지면 높이의 측면 단면. 썰매 앞에 모래가 쌓이는 과정. 전체 썰매 길이 유지. | 썰매가 나아갈수록, 앞에 모래더미가 생겼거든요. |
| 04 뜻밖의 물줄기 | 위에서 내려다본 물 붓기. 항아리에서 나온 물이 썰매 앞의 좁은 경로를 적신다. | 그런데 썰매 앞에 물을 조금 부으면요? |
| 05 움직이기 시작 | 낮은 측면 추적 화면. 모래더미가 줄고 썰매가 목적지 방향으로 나아간다. | 앞을 막던 모래가 줄어들고, 한결 쉽게 움직입니다. |
| 06 손으로 보는 차이 | 손에서 흩어지는 마른 모래와 형태를 유지하는 젖은 모래의 시연. | 젖은 모래로 모래성을 만들면, 모양이 잘 잡히죠? |
| 07 모래 속으로 | 전체 화면을 모래알 설명 그림으로 전환. 작은 물 연결과 많은 빈 공간. | 물이 모래알을 연결해서, 바닥을 더 단단하게 만드는 겁니다. |
| 08 많이 부으면? | 동일한 작은 썰매/돌의 비교 시연. 적당히 젖은 모래와 과도하게 젖은 모래. | 그렇다고 많이 부으면 더 좋을까요? 너무 젖으면 다시 끌기 어려워집니다. |
| 09 벽화에 남은 단서 | 벽화 재구성을 화면 전체에 보여주고 물 붓는 인물을 표시한다. | 실제 이집트 벽화에도, 썰매 앞에 물을 붓는 사람이 있습니다. |
| 10 도착과 회수 | 01에서 멀리 보이던 목적지 앞. 같은 석상과 썰매, 당기기를 마친 인물, 뒤로 이어지는 이동 경로. | 거대한 석상을 옮기는 힌트가, 작은 물줄기에 있었던 거죠. |

초안 단계에는 장면 시간을 고정하지 않았다. 제작 v1은 원본 필재 음성을 측정한 뒤 43초로 확정했다. 설명을 자르지 않고, 음성은 음높이를 유지하면서 0.94배 속도로 조정했다. 최종 시간표는 production-v1.json과 production.md를 따른다.

## 정확성

- 역사 장면의 장소, 작업 인원, 인물 반응, 출발·도착 상황은 설명용 재구성이다. 특정 실제 운반 사건의 기록처럼 소개하지 않는다.
- 제후티호테프 벽화에 썰매 앞에 물을 붓는 인물이 있다. 그 행위의 역사적 의도와 적용 범위에는 해석이 개입한다.
- 젖은 모래의 견인력 감소와 과도한 수분에서 다시 증가하는 현상은 현대 실험 근거다. 비교 실험은 역사 장면이 아닌 원리 설명이다.
- 물이 윤활막을 만들어 석상을 띄우는 것처럼 표현하지 않는다. 입자 접촉점에 작은 물 다리를 보여준다.
- 모든 모래와 무게에 동일한 수분량이 최적이라고 말하지 않는다. 숫자/인원 절반/피라미드 전체 해명으로 확대하지 않는다.
