# 샤두프 — 제작 v2

53초·20장면·1080×1920·24fps·원본 필재·한국어. 풍경 위에 별도 도해가 겹친 v1을 수정했다. 03·07·08·09·12·13·15·16·20은 풍경을 제거한 아이보리 설명 화면이다. 15·20의 합성 수면도 없애고 독립된 붓기/전체 원리 애니메이션으로 교체했다. 나머지10장면의 힉스필드 인물 영상을 재사용하며, 한 장면에는 한 종류의 화면만 나온다.

## 역사 자료

19는 [The Met의 Garden Scene, Tomb of Ipuy](https://www.metmuseum.org/art/collection/search/557816), 소장번호30.4.115를 전체 화면으로 사용한다. Norman de Garis Davies가 실제 고대 벽화를 옮겨 그린 종이 위 템페라 복제본이다. 원래 고대 벽의 사진이라고 부르지 않는다. 고대 원본 표기는 약기원전1290–1224년, Rogers Fund1930, Public Domain/Open Access. 영상에서는 프레임을 제외한 세로 크롭과 팬만 사용한다. 칠해진 인물/도구는 애니메이션으로 변형하지 않았다. 출처/라이선스/크롭/이미지해시는 production-v2.json에 있다.

## 비용과 보존

추가 유료 생성0, 추가 힉스필드 크레딧0. 기존 누적43.75(최초37.5+붓기 보완6.25), 상한50/남은6.25 미사용. v2에서 사용하지 않는 붓기 보완 클립의 기존 비용도 누적에 포함한다. Typecast399자 원음도 재사용했으며 새 음성 생성은 없다. 기존 v1영상과 production-v1.json은 비교용으로 보존한다.

## 화면·음성·동작

설명 배경은 단색아이보리#F5EFDF이며 풍경이 없다. 장치 높이를 보여주는 도해용 땅/수로만 남긴다. 질감 있는 목재/흙/가죽, 막대 길이와 반대편 추, 물통 설치와 수위, 붓기/수로 흐름을 유지한다. 작은 이펙트는 물줄기가 실제 받이 수면에 닿는 곳에만 넣는다. 이전의 합성 수면과 풍경 중첩은 제거했다. 최종MP4 자체가 투명 영상인 것은 아니며, 설명 화면이 독립적으로 전체를 채운다.

원본 필재/0.94배 음높이 유지/음성 파일50.795초/발화 끝50.54초/화면53초. 원문과22개 자막 구간,26개 낮은 효과음 이벤트를 그대로 재사용한다. 전역layoutv6 제목(540,260)/설명(540,1360), 자막64px/최대2줄/의미별 개행을 유지한다. 글자 패널은 없다.

이 영상은 모든 장치를 실측 복원한 역학 시뮬레이션이 아니다. 최초 발명자/성능 배수/자동 운전/피라미드 운반 장치라는 주장은 하지 않는다. 진짜 역사 자료19는 정지 원화의 카메라 관찰이며, 실제 동작 장면을 대체한 것으로 계산하지 않는다.

## 환경과 명령

Python3.12/Pillow/NumPy, FFmpeg/FFprobe9, Noto Sans KR. 원리 설명은 직접 만든 질감 있는 기하 렌더러이며 Blender 실행 결과가 아니다. 원음/타이밍/자막레이어와 기존 클립은 work/egypt-shaduf/production-v2에 로컬로 재사용했다. 원리 화면 렌더→기존 컷 연결→같은 제목/자막과 음성 합성→전체검수 순서다. 제작Python과 미디어는 Git에 포함하지 않는다.

```powershell
.\scripts\validate-layout.ps1
ffprobe -v error -show_streams -show_format -of json .\outputs\egypt-shaduf-final-v2.mp4
ffmpeg -v error -i .\outputs\egypt-shaduf-final-v2.mp4 -map 0:v -map 0:a -f null -
```

위 명령은 레이아웃과 기존 결과 검수용이다. 원음/영상 생성 요청을 다시 보내지 않는다. 다른 PC에는 필요한 도구/Typecast와 힉스필드 연결을 새로 설정하고 production-v2.json의 원리 화면/타임라인/자료설정을 적용한다. 전역active_topic은 이번 수정으로 바꾸지 않았다.
