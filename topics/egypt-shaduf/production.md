# 샤두프 — 제작 v1

53초·20장면·1080×1920·24fps·한국어 최종 영상. 문제에서 운반의 수고, 막대와 추의 도움, 물 올리기, 사람의 반복 조작, 수로로 물 보내기까지 이어진다. 승인한 그림체와 원본 필재, 공통 layout v6을 유지했다.

## 실제 비용

최초4개 영상은5·10·5·10초로37.5크레딧, 필수 붓기 보완5초는6.25크레딧. 합계 **43.75크레딧**이며 제출 전 개별 견적과 전체 잔액 차이로 확인했다. 50은 상한이며 목표가 아니다. 남은6.25는 쓰지 않았다. Typecast399자와 기본 이미지 생성 도구 사용량은 별도다. paid upscale/이미지/오디오/렌더는 추가하지 않았다. 생성 후반부를 일부 잘라 사용하더라도 제출 비용 전체를 포함한다.

## 연결과 보정

생성된5개 클립을12장면에 나눠 쓰고,03·07·08·09·12·13·16·19는 직접 만든 설명 애니메이션으로 구성한다. 17·18·20은 실제 작업을 반복한다는 내레이션에 맞춘 두 번째 운반 순환이다. 전체를 정지 이미지 줌/팬으로 채우지 않는다. 원리 설명에서는 고정된 받침점·막대 길이·추 위치를 지키고 실제 물통/추·수위/수로 물/시연 표시를 움직인다.

10초 들어 올리기 생성본의 후반부는 요청한 붓기 대신 다시 내리는 동작이어서 제외했다. 별도5초 클립의 인물 기울임은 사용하고, 물줄기가 받이를 지나 낮은 강으로 내려가는 부분은 깨끗한 환경과 직접 만든 높은 받이 수면/작은 충돌 효과로 보정했다. 이후16의 수로 도해로 밭 쪽 배수를 설명한다. 마지막 막대 끝이 제목에 겹치지 않게15·20의 영상만64px 아래로 재배치했다. 제목/자막 좌표는 바꾸지 않았다.

직접 도해는 실측 복원이나 모든 생성 프레임의 정확한 역학 시뮬레이션이 아니다. 인물·정확한 땅 모양·받이 구조는 설명용 재구성이다. 19의 벽화는 승인 콘티의 재구성 그림이며 실제 소장품 사진/정확한 복제라고 주장하지 않는다. 샤두프의 최초 발명자/정확한 발명 연대/성능 배수/피라미드 운반 장치라는 주장은 하지 않는다. 자료 링크는 storyboard-v1.md를 따른다.

## 음성·자막·소리

원본 Typecast 필재는 인증된 카탈로그에서 확인했으며 대체 음성을 쓰지 않았다. 연속 음성을 음높이를 유지한0.94배로 조정해 파일50.795초, 마지막 발화50.54초, 화면53초에 맞췄다. Whisper medium의 단어 시각으로 자막을 배치하고 원문399자/22의미 단위를 보존했다. 인식 유사도는 약0.982이며 ‘샤두프’처럼 인식된 철자는 원래 대본으로 표시했다. 이름의 별도 발화 구간은 실제 ASR 시각47.04~47.86초로 맞췄다.

제목 중심(540,260), 자막 중심(540,1360), 설명64px/최대2줄/의미별 선개행. 흰색과 노란색 강조/검은 외곽선·그림자, 자막 패널 없음. 낮은 강물·입수/붓기·발걸음·나무/밧줄·전환 효과음을 음성 아래에 넣었고 배경 음악은 사용하지 않았다.

## 환경과 명령

로컬 Python3.12/Pillow/NumPy, FFmpeg/FFprobe9, faster-whisper medium CPU, Noto Sans KR 가변 글꼴, Higgsfield 연결과 Typecast 인증을 사용한다. 원리 장면은 직접 만든 질감 있는 기하 렌더러이며 Blender 실행 결과라고 주장하지 않는다. 키는 사용자 로컬 암호화 파일에 두고 다른 PC에서는 본인 환경에서 새로 설정한다.

```powershell
.\scripts\validate-layout.ps1
.\scripts\connect-typecast.ps1 -GenerateNarration -ScriptPath .\topics\egypt-shaduf\narration.txt -OutputPath .\work\egypt-shaduf\production-v1\piljae-raw.wav
ffprobe -v error -show_streams -show_format -of json .\outputs\egypt-shaduf-final.mp4
ffmpeg -v error -i .\outputs\egypt-shaduf-final.mp4 -map 0:v -map 0:a -f null -
```

Typecast 명령은 음성을 새로 생성하므로 이미 완성된 영상 검수에는 실행할 필요가 없다. 이 명령들은 연결/검수용이며 다른 PC에서 전체 영상을 자동 재생성하는 단일 명령이 아니다. 사용자가 제작 소스는 Git에 올리지 않도록 요청했으므로 로컬 work/에만 보관한다. 다른 작업자에게 production-v1.json의 프롬프트·클립 구간·기하/합성 설정·자막 시각을 전달해 같은 프로세스를 적용한다. 전역 active_topic은 변경하지 않고 이번 topic.json을 명시적으로 선택한다.

## 결과 및 검사

영상 outputs/egypt-shaduf-final.mp4, 자막 outputs/egypt-shaduf.srt, 검수 outputs/egypt-shaduf-verification.json. 53초/1272프레임·H.264/AAC 전체 디코딩, 음성 피크/끝부분, 원문 자막, 전역 안전 영역, 장면별 움직임 샘플을 확인했다. 인코딩된20장면/마지막 프레임과9:16·9:19.5·9:20 UI 시뮬레이션을 검토했다. 화면 시뮬레이션은 모든 휴대폰의 실제 UI를 보증하는 기준이 아니다.

Git에는 설정·프롬프트·대본·명령·제작 기록만 보관한다. 영상·이미지·제작 코드·키·업로드 주소·개별 작업 영수증은 제외한다.
