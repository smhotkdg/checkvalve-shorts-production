# 고대 이집트의 샤두프

다음 주제: ‘나일강 옆인데 밭에 물이 없었다?’. 문제→운반의 수고→추를 단 막대→연속 물 올리기→사람의 반복 조작→수로와 밭의 결과. 단순 부품 작동 설명에서 끝나지 않으며 약 60초/20장면으로 구성한다.

20장면 콘티 이미지·텍스트와 한국어 대본, 의미 단위 자막 선개행, 제목/설명, 그림 프롬프트를 준비했다. 승인받은 이집트/폼페이 그림체와 공통 layout v6을 유지한다. 장면 수와 유료 생성 수는 다르며, 실제 영상 제작 전 목재 막대·물통·추의 반대 동작과 물 부피를 확인한다.

기본 제작은 Higgsfield 인물 동작 + 정확한 직접 애니메이션 + 원본 Typecast 필재. 모든 장면은 실제 과정/인물/물/시연이 움직이도록 한다. 콘티의 20개 구도·조립 순서·물통 상태를 확인했고, 자막 원문/64px 줄 폭/안전 영역도 검사했다. 완성 영상/유료 생성/TTS는 아직 제출하지 않았다. 5초 Standard 샘플 견적6.25 × 임시4개=25크레딧은 계획값, 최종 견적 아님. 상한50을 채우지 않는다.

자료와 20장면 표는 storyboard-v1.md, 프롬프트는 storyboard-v1.prompt.txt를 따른다. 콘티 이미지와 제작 미디어는 로컬만 보관한다.
