# 고대 이집트의 샤두프

최신 v2: 53초·20장면·한국어. 힉스필드 풍경 영상 위에 직접 만든 도해를 겹치던 구성을 없앴다. 10장면은 기존 힉스필드 인물 영상, 9장면은 풍경 없는 아이보리 설명 화면, 19번은 실제 박물관 벽화 복제본을 세로 전체 화면으로 보여 준다.

낮은 강물과 높은 밭의 문제→운반의 수고→막대와 추→물 올리기→사람의 반복 조작→수로와 밭으로 이어지는 대본은 그대로다. 설명에서는 설치·물통/추 이동·수위 상승·붓기·수로 흐름을 움직인다. 역사 자료 속 인물은 움직이지 않으며, 원본의 크롭/팬으로 관찰한다.

53초·1272프레임, 원본 필재 음성, 22개 의미 단위 자막, 효과음과 전역 layout v6 유지. 제목 중심(540,260), 자막 중심(540,1360), 자막64px/최대2줄. 재합성한 장면과 휴대폰 UI 비율을 검토하고 전체 디코딩·음성·원문 자막·안전 영역·장면별 움직임 샘플을 확인했다.

이번 수정의 추가 힉스필드/Typecast 생성은0. 기존 힉스필드 누적43.75크레딧은 버린 붓기 클립의6.25도 포함한다. 상한50 중6.25를 쓰지 않았다. 기존 Typecast399자 사용량은 별도다.

자료19: The Met, Garden Scene, Tomb of Ipuy,30.4.115. Norman de Garis Davies가 옮겨 그린 종이 위 템페라 복제본이며 원래 고대 벽 자체의 사진은 아니다. 공개 자료의 크롭을 사용했고 그림 내용은 바꾸지 않았다. 나머지 인물/장치/풍경은 설명용 재구성이다.

최신 설정은 production-v2.json, 제작 기록/환경/명령은 production.md. production-v1.json과 storyboard-v1.md는 이전 제작/콘티 기록이다. 영상·이미지·제작 소스·키·업로드 주소는 Git에 올리지 않는다.
