# 고대 이집트의 샤두프

53초·20장면·한국어 최종 영상 제작 및 검수 완료. 낮은 강물과 높은 밭의 문제→물통 운반의 수고→막대와 추→물 올리기→사람의 반복 조작→수로와 밭의 결과로 이어진다. 60초 콘티 가시간은 원본 필재 발화를 측정해 53초로 맞췄다.

Higgsfield 인물 동작과 직접 만든 물통/추/수위/수로 설명 애니메이션, 원본 Typecast 필재를 연결했다. 생성 클립5개를12장면에 쓰고8장면은 직접 애니메이션이다. 17·18·20의 동작 재사용은 사람이 두 번째 순환을 반복한다는 설명을 위한 것이다. 정지 그림의 확대/이동만으로 장면을 채우지 않았다. 그림 기록19는 움직이는 검사 표시로 장치를 따라간다.

실제 Higgsfield 사용량43.75크레딧: 최초5·10·5·10초 클립37.5 + 필수 붓기 보완5초6.25. 모든 제출 견적과 잔액 차이로 확인했으며, 잘린 생성 후반부도 비용에 포함했다. 상한50 중6.25는 쓰지 않았다. Typecast399자와 기본 이미지 생성은 별도 사용량이다.

자막은 원문22개 의미 단위, 공통 layout v6의 제목(540,260)/설명(540,1360), 설명64px/최대2줄을 유지한다. 물·발걸음·목재/밧줄·작은 전환 효과음을 낮게 넣었다. 전체 디코딩,53초/1272프레임, 음성 끝, 원문 자막, 안전 영역, 장면별 움직임 샘플을 검사하고 인코딩 화면/마지막 프레임/휴대폰 비율 시뮬레이션을 확인했다.

최신 설정은 production-v1.json, 제작 기록/환경/명령은 production.md를 따른다. storyboard-v1.md는 최초 콘티 기록이다. 원리 도해와 인물/풍경은 설명용 재구성이며 실측 복원이나 실제 발명 현장으로 주장하지 않는다. 미디어·제작 소스·키·업로드 주소는 Git에 올리지 않는다.
